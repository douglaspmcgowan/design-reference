This project moved

The Design Library replaced this reference.

The Slide & Poster Design Reference was sixteen CSS style demos on one page. Everything it did is now one section of a much larger library — rebuilt, measured, and still free.

Go to the Design Library

What is there now

  • 17 complete design languages, each with a rendered page and a specification sheet that computes every contrast pair in the palette.
  • 16 aesthetic styles — the successors to this page's demos, each rebuilt as a full page with live examples and the CSS recipe.
  • A workbench for editing a language's tokens against a real product surface, with a continuous WCAG readout.
  • A compare view, nine application fittings, foundations pages for type, colour, layout and motion, and a directory of design systems elsewhere on the web.

Every path on the old site now answers 308 and points at the new one, so old links keep working. The original gallery is still in this repository's git history if you want it.
