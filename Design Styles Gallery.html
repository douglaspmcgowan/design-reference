01 — AESTHETIC MOVEMENTS

Design styles & aesthetics

The big meta-trend of 2026 is humanity as a signal against AI sameness: raw, hand-made looks (neubrutalism, anti-design, Y2K, kinetic type) are surging, while bento, dark mode and aurora gradients won the polished side. Each demo is a real recreation you can study.

Glassmorphism

Stable

Translucent frosted panels floating over color or photography, with a hairline light-catching border and a real backdrop blur. Apple's “Liquid Glass” gave it new credibility; the backlash came from overuse.

Best for: overlays, modals, nav, tech/SaaS hero cards. Use it on one or two surfaces.

Dark mode / dark-glass

Rising

A dark-first philosophy: near-black warm bases, elevation expressed through brightness and subtle light borders, desaturated accents that glow. Pairs naturally with aurora and glass.

Best for: dev tools, SaaS, media, high-tech decks, anything used in the evening.

Rising

Large blurred color blobs blended over a dark base, like northern lights. Often animated for depth. The “living gradient” that replaced flat fills, signalling tech polish.

Best for: dark-mode backgrounds, title and section slides, SaaS hero sections.

Rising

Make it accessible

  • WCAG AA = 4.5:1 for body text, 3:1 for large headings (≥24px). AAA = 7:1 / 4.5:1.
  • On dark backgrounds viewers read by luminance, so span a wide brightness range.
  • Grayscale-test every palette: if it reads in gray, it survives colorblindness.
  • Use pattern fills on charts (hatch/dots), so color is never the only signal.

Okabe-Ito (colorblind-safe)

60-30-10: 60% dominant neutral, 30% secondary surfaces, 10% accent. Keep the accent scarce, like punctuation. Mix one warm/earthy tone with one sharp digital accent for the signature 2026 look.

05 — MAKE IT

How to actually build it

Three production paths. PowerPoint for reach and control, HTML for code-grade precision and version control, print tools for posters and flyers. Match the tool to the deliverable and the audience.

▦

PowerPoint & decks

Maximum reach and control. The default look reads dated, so the work is in the system you build.

  • Slide Master + layouts: one source of truth for type, color and placeholders. Edit the master, never single slides.
  • Theme colors & fonts: define a palette + heading/body pair once, so recoloring cascades everywhere.
  • Morph transition: duplicate a slide, move an object, apply Morph. Prefix matched names with !! to force a 1:1 morph.
  • Designer: AI layout suggestions as a starting point; then strip the clutter.
  • Icons & SVG: Insert > Icons, then right-click > Convert to Shape to recolor paths.
  • Assertion-Evidence: a full-sentence headline states the claim; the body is one visual that proves it.
  • Tool landscape: Gamma (prompt to polished), Beautiful.ai (auto-on-brand), Pitch (team decks), Canva (asset library), Keynote (best animation). Tome shut down its deck product in 2025.

HTML / CSS slides

Code-grade control, version control, real code blocks and unlimited animation. Markdown decks are AI-native.

  • Slidev: Markdown + Vue, the developer favorite. Live reload, Shiki code morphing, presenter mode, export to PDF/PPTX.
  • reveal.js: the mature, flexible standard; embeddable vanilla JS, biggest plugin ecosystem.
  • Marp: minimalist Markdown to HTML/PDF/PPTX with the best PowerPoint export and a VS Code preview.
  • Spectacle (React/MDX) and impress.js (Prezi-style zoom) for niche needs.
  • Techniques: Shiki / Prism syntax highlighting, Mermaid diagrams, KaTeX math, CSS scroll-snap, Tailwind for slides, print-to-PDF.
  • Why bother: plain-text decks live in Git, code is first-class, and the browser ceiling is unlimited.

Posters & flyers

Built for a wall and a glance. For academic posters, lead with the finding and let figures dominate.

  • Better Poster (#betterposter): one giant plain-language finding in the center, narrow sidebars for method and limitations, a QR code, and a short summary bar.
  • Sizes: A0 (841×1189mm) international, 48×36" US. Confirm the venue rules first.
  • Readability: body ≥24pt, sans-serif, left-aligned, legible from a meter away. Roughly 20% text, 40% figures, 40% whitespace.
  • Tools: PowerPoint as one giant slide (300dpi PDF), Canva, Affinity Publisher (one-time buy), InDesign, or LaTeX (beamerposter / tikzposter).
  • Flyers: one focal point, a Swiss grid, and 2–3 colors at scale. Type can be the image.
